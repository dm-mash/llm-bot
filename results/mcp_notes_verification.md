# Собственный MCP-сервер + вызов инструмента агентом — отчёт

Задание: реализовать свой MCP-сервер вокруг любого API (регистрация
инструмента, описание входных параметров, возврат результата), подключить
инструмент к агенту, вызвать его из приложения и использовать результат.

Выбранный API: **mock-CRM «заметки»** — записи в JSON-файле (`NOTES_DB`,
по умолчанию `data/notes.json`). Сеть и API-ключи не нужны, поведение
детерминировано.

## Компоненты

| Компонент | Файл | Роль |
| --- | --- | --- |
| Mock-CRM API | [`llm_bot/notes_api.py`](../llm_bot/notes_api.py) | `add_note` / `list_notes` / `find_notes` над JSON-файлом |
| MCP-сервер | [`scripts/notes_mcp_server.py`](../scripts/notes_mcp_server.py) | FastMCP, stdio, 3 инструмента |
| Мост + роутер | [`llm_bot/mcp_tools.py`](../llm_bot/mcp_tools.py) | `MCPToolBridge` (соединение с сервером), `MCPRouter` (агрегация, неймспейс `server__tool`, изоляция ошибок) |
| Интеграция | [`llm_bot/agent.py`](../llm_bot/agent.py), [`llm_bot/factory.py`](../llm_bot/factory.py), [`llm_bot/cli.py`](../llm_bot/cli.py) | блок инструментов в префиксе, цикл директивы, `--mcp`, `--list-mcp` |
| Конфиг | [`mcp.example.yaml`](../mcp.example.yaml) → `data/mcp.yaml` | список серверов (stdio/HTTP), шаблон для добавления новых |

## Пункты задания

1. **Регистрация инструмента** — декоратор `@mcp.tool()` в сервере; каталог
   отдаётся через `tools/list`:

   ```
   $ python -m llm_bot --list-mcp
   - notes: python scripts/notes_mcp_server.py
       - add_note: Добавить заметку в CRM. Возвращает подтверждение с id заметки.
       - list_notes: Список заметок, при указании *tag* — отфильтрованный по тегу.
       - find_notes: Найти заметки по подстроке в тексте или тегах.
   ```

2. **Описание входных параметров** — типизированные сигнатуры FastMCP
   превращаются в JSON Schema. Проверено тестом
   [`test_server_lists_tools_with_schemas`](../tests/test_mcp_notes_server.py):
   у `add_note` обязательны `text`, опционален `tags`; у `find_notes`
   обязателен `query`.

3. **Возврат результата** — текст вида `Заметка сохранена: id=1, теги: покупки`;
   невалидный вход возвращает MCP-ошибку (`isError`), не роняя сервер.

## Вызов из приложения (агент → MCP)

Так как [`LLMClient`](../llm_bot/client.py) говорит на чистом
chat-completions (без нативного `tools`), используется промптовый протокол:
роутер инъектирует системный блок с каталогом и инструкцией «если нужен
инструмент, ответь `{"call_tool": {...}}`», а при нескольких действиях в
одном запросе («добавь три заметки») — пакетом
`{"call_tool": [{...}, {...}, ...]}`: все вызовы выполняются за один
раунд-трип и не расходуют лимит раундов. `Session` распознаёт директиву(ы),
выполняет вызовы через `MCPRouter`, результаты уходят сервисным ходом, модель
даёт финальный ответ (максимум `mcp_max_rounds=2` раундов на ход).

Живой прогон (`python scripts/mcp_notes_demo.py`, реальный LLM):

```
>>> Запиши в CRM заметку «купить корм коту» с тегом «покупки».
Заметка успешно сохранена в CRM: «купить корм коту», тег «покупки», идентификатор записи 1.
    [mcp] notes__add_note OK: Заметка сохранена: id=1, теги: покупки

>>> Выведи список всех заметок, которые сейчас лежат в CRM.
Список текущих заметок в CRM:
1. Текст: купить корм коту  Теги: покупки  ID: 1

notes DB after the demo:
[ { "id": 1, "text": "купить корм коту", "tags": ["покупки"] } ]
```

Запись реально оказалась в JSON-файле — результат инструмента использован
агентом, а не придуман.

пользователю.

## Политика ошибок запуска

Явный `--mcp <имя>` при отсутствии/пустом `data/mcp.yaml`, при неизвестном
имени сервера или когда выбранные серверы не отдают инструментов — это
`ValueError` при старте процесса (с подсказкой скопировать
`mcp.example.yaml`). Тихое отключение функции уместно только когда флаг
`--mcp` вообще не указан: тогда отсутствие конфига = MCP выключен.

## Расширяемость

Новый MCP-сервер подключается записью в `data/mcp.yaml` (команда stdio или
URL HTTP) и выбором через `--mcp name1,name2` / `--mcp all`. Роутер
неймспейсит инструменты (`notes__add_note`, `time__get_current_time`) и
маршрутизует вызовы; примеры `time` и `deepwiki` уже в шаблоне конфига.
